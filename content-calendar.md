# Content Calendar

Agents propose; the human approves. This is a living plan, not a publish trigger.
Nothing here goes live until the matching draft is approved and moved to `approved/`.

## Status legend
- proposed: agent suggested, not yet reviewed
- approved: human signed off; ready for publish layer
- published: posted (see SOCIAL_PROGRESS.md for the record)
- archived: not used / superseded (kept, not deleted)

## Weekly themes (draft — edit freely)
- Project updates: what shipped / what's next on NoUs.
- Mission: data rights, "safety through severance," personal-data-as-a-human-right.
- Community: highlight contributors, answer questions, share discussion.
- External news: relevant Big Tech / privacy / data-rights developments with NoUs's take.

## Cadence guardrails
- Start small: a few posts/week, scale only after the approval loop feels smooth.
- Respect each platform's rate limits and ToS. No cross-posting spam.
- Every published item gets a row in SOCIAL_PROGRESS.md.
