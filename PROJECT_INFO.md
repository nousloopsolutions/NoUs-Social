# NoUs — Project Reference (for social agents)

Reference material so content agents represent the project accurately. Source: the
NoUs-hub repository README (the canonical "single source of truth"). Keep this file in
sync if NoUs-hub's description changes. Public site: https://nousloop.com

## What NoUs is
NoUs Loop Solutions is building a sovereign, privacy-first AI system. The work is
consolidated in one canonical monorepo, NoUs-hub (the "Sovereign Megahub"),
established March 2026, which holds all logic, UI, ops, and documentation for the
long-term NoUs IP. Core idea: keep cognition local and user-controlled rather than
dependent on Big Tech infrastructure.

## Mission backbone
"Safety through severance" — advancing data rights and treating personal data as a
human right, with the long-term aim of severance from Big Tech. Content should ladder
up to this theme.

## Architecture in plain terms (six tiers)
The system is organized into six layers with fixed boundaries:
1. Floor — the cognitive core / engine (math, memory, offline language processing).
2. Elevator — a security gateway mediating between the interface and the engine.
3. Surface — the desktop and web interfaces people actually use.
4. Mobile — an Android edge node for sensory input.
5. Ops — infrastructure, orchestration, and deployment.
6. Vault — cold storage / audit trail for retired logic.

## Notable components (context, not jargon to repeat verbatim)
- A local-first cognitive engine emphasizing memory over long time horizons.
- SAID: social-awareness / insight-detection capabilities.
- Mind-Sentinel: offline analysis with local models and strict network policies.
- Wonderland desktop: the primary desktop interface.
