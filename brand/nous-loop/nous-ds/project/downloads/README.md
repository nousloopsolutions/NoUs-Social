# NoUs Loop brand marks (SVG)

Standalone SVGs: styles, colours and animation are built into each file. No fonts or other files needed.
They animate when opened in a browser or placed with `<img src="...">`; the `-still` files are motionless (print, merch, stickers).

| File | What |
| --- | --- |
| nous-loop-wordmark.svg | NoUs L∞P, animated (two-act cycle, 28s), transparent background |
| nous-loop-wordmark-still.svg | NoUs L∞P, still, transparent |
| nous-loop-wordmark-wall.svg | animated, on the war-torn wall (banners, headers) |
| nous-loop-wordmark-wall-still.svg | still, on the wall |
| nous-loop-owl-watching / -severing / -alert / -calm.svg | the mechanical owl, one animated file per expression |
| nous-loop-owl-still.svg | the owl, still, transparent |
| nous-loop-owl-wall.svg | the owl on the wall, square (avatars) |
| nous-loop-emblem.svg / -still.svg | the impossible pyramid, animated / still |
| nous-loop-emblem-avatar.svg | the emblem on the wall, square (profile pictures) |
| nous-loop-severing-loader.svg | the severing… loader |

Neon colours are designed for dark backgrounds. People who turn off motion in their system settings see the marks hold still.
Need PNGs? Open any file in a browser and export, or ask Claude to render them.
